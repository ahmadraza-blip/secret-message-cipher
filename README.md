# Secret Message Cipher

A Python-based text encoding and decoding utility that applies string manipulation techniques to transform and recover messages.

## Overview

This project demonstrates how Python string operations can be used to create a simple custom message cipher. It uses techniques such as string slicing, padding, character modification, and reversal to encode and decode text.

## Features

- Text encoding and decoding
- String slicing
- String reversal
- Padding and character modification
- Simple command-line implementation

## Technologies Used

- Python 3
